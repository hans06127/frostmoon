## 插圖使用原則

- 閱讀順序應自然形成：文字 -> 插圖 -> 文字。
- 插圖應與前後劇情直接相關。
- 不提前暴露尚未揭露的真相、角色身分或世界觀資訊。
- 優先放在場景首次揭露、角色重要登場、身分轉折、情緒停頓或視覺高潮。
- 不連續堆太多圖片，避免破壞懸疑與閱讀節奏。
- Web 優先使用 WebP 或 AVIF。
- 若角色會反覆生成插圖，需保留角色視覺一致性設定。

## 角色一致性

反覆出現的角色圖應保存基準描述，至少包含：

- 年齡感與身形輪廓
- 髮型、髮色、眼神與主要表情
- 服裝層級與常見配色
- 傷痕、限制器、改造痕跡或其他辨識特徵
- 圖像不應揭露當前章節尚未公開的秘密

## 插圖放置建議

在 Markdown 或 MDX 中放置插圖時，應讓插圖靠近對應場景，並保留替代文字。

```md
![霜月莊園夜景](/images/chapters/ch01-manor-night-v01.webp)
```
