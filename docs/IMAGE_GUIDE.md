# 圖片指南

正式章節插圖放在：

```text
public/images/chapters/arc-01/ch001/scene-01.webp
```

在 Markdown 對應段落間引用：

```md
![不暴雷且能描述畫面的替代文字](/images/chapters/arc-01/ch001/scene-01.webp)
```

優先使用 WebP 或 AVIF，並控制檔案尺寸。插圖應服務場景、情緒或資訊揭露，不應提前暴雷；角色重複出現時需維持外觀與服裝設定一致。

萬象集圖片放在 `public/images/archive/<category>/`，資料登錄方式見 `docs/ARCHIVE_GUIDE.md`。

角色圖鑑圖片固定放在 `public/images/characters/`，由 `content/characters/*.md` 的 `portrait` 與 `gallery` 引用。

## 雙月苑建築圖像基準

- 雙月苑是大型私人園區，不是單棟莊園。
- 左右各一棟大型半月形建築，凹面朝向中央；左棟形似 `)`，右棟形似 `(`。
- 入口位於南側。由入口往北依序為主車道、中央寬闊景觀水池、中央主棟，以及主棟後方獨立的訓練暨研究樓。
- 鳥瞰識別必須清楚呈現「左右雙月＋中央核心」。中央水池採低矮、寬闊、幾何化設計，使用平靜深色水面、水下照明、環池步道與局部倒影。
- 中央主棟是權力中心。訓練暨研究樓不得使用半月造型，應方正、現代、功能導向，以玻璃、金屬與石材為主，可包含地下空間或空橋。
- 整體風格為「現代奢華私人設施＋近未來科技＋大型住宿園區」；環境乾淨、漂亮且維護良好，壓迫感來自制度、監控與隱藏科技。
- 不使用哥德城堡、尖塔、中世紀城牆、腐敗鬼屋、純歐式莊園，或較早版本的「上下一對弧形建築」。
- 地面視角不必完整拍到左右雙月；鳥瞰、高角度與總配置參考圖必須完整交代兩棟半月建築及中央軸線。

## 後續重做順序

第一張正式參考圖應為「雙月苑總配置鳥瞰設定圖」，先固定左右半月、中央水池、主棟、後方訓練暨研究樓、入口方向、主車道、植栽與相對尺度。之後所有外觀圖均由此設定圖延伸。

建議依序建立：

1. 雙月苑總配置鳥瞰設定圖。
2. 大門與入口視角。
3. 中央核心區的地面視角。

`content/source/` 內的歷史素材維持原樣，不因圖像重做而修改。
