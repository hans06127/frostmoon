# CONTRIBUTING

本文件規範 Frostmoon 專案的修改流程。

## 修改單位

正文修改應以清楚、可回顧的範圍為單位：

- 一章
- 一組小節
- 一個角色弧線問題
- 一個設定問題
- 一個時間線或伏筆問題

## 修改前檢查

- AI 或人工修改前，應先讀相關章節。
- 必要時讀前後章、設定文件與角色資料。
- 發現設定矛盾、時間線錯誤、人物行為不合理或伏筆斷裂時，應主動指出。
- 不要默默把矛盾改成另一套設定，除非修改目標明確要求。

## 劇情與尺度

- 不要因為降尺度而把作品改成清水小說。
- 不要無理由增加成人場景。
- 成人內容應服務劇情、角色、心理、權力關係、身分錯位或懸疑資訊。
- 重大劇情、角色身分、時間線、真相揭露位置變更，應先更新 outline 或留下說明。

## 前端與內容

- 本專案預期同時包含小說正文、插圖與閱讀網站。
- 不要因單次正文修訂而重構前端。
- 不要因單次前端調整而搬動大量正文檔案。
- 若需要大型重構，先提出方案與風險，不直接執行。

## Commit 命名建議

```text
rewrite: 重寫第一章 1-3 至 1-5
story: 調整沈若冰身份揭露順序
fix: 修正第二章時間線
art: 新增第一章插圖
docs: 更新內容規範
site: 改善手機閱讀版面
```
