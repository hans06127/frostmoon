# 小說指南

本文件是 Frostmoon 修訂版正文的主要準則，已同步 TT ChatGPT 專案規則與目前確認的故事設定。

## 作品

- 專案名稱：Frostmoon
- 小說名稱：《我只是來打工的，沒人說過工作內容會變成這樣吧？》
- Arc 01：霜月莊園
- Arc 02：克萊因學院
- Arc 03：未定

## 核心作品方向

1. 作品核心為黑暗懸疑、臥底、身分置換、身體改造、權力控制、人物關係與身分認同。
2. 保留成人感、羞恥感、曖昧、壓迫感與身體改造元素，但不要將作品改成純色情小說，也不要過度清水化。
3. 成人相關內容必須服務至少一項功能：劇情推進、人物關係、心理變化、權力關係、身分錯位或懸疑資訊。
4. 若成人內容只有重複刺激效果而沒有新的劇情功能，應縮短、淡化、合併或刪除。
5. 性相關橋段優先描寫心理、羞恥、控制、依賴、界線、恐懼與人物關係，降低器官、體液、尺寸與連續刺激細節。
6. 強迫、控制、監禁、人體改造等情節可以存在，但敘事必須承認其侵犯性與心理後果，不要自動將其視為浪漫福利。

## 人物處理原則

1. 唐凜的核心成長線為：被迫偽裝 → 排斥 → 適應 → 熟練 → 身分錯位 → 唐凜與「秦夢瑤」產生心理衝突。
2. 不要讓唐凜快速接受重大身體或身分改變。重要改變後必須安排心理消化與生活適應。
3. 沈若冰必須保持多義性。讀者不能太早確定她究竟是在利用、培養、控制、保護唐凜，還是真正對他產生感情。
4. 唐凜與沈若冰的信任、依賴、曖昧、背叛感與親密感必須循序發展，不得突然跳級。
5. 西奧的核心應放在「克萊因孩子」、異常能力、限制器、身世與心理依附，而不是將她單純作為成人橋段角色。
6. 新角色必須具有明確的角色功能、欲望、秘密或衝突，不要只為單一場景服務後就消失。

## 角色視角與語氣

- 唐凜：口語、會吐槽、自我解嘲、反問與碎念，但不是習慣性挑釁型人物。面對高權力角色時節制口頭反抗，尖銳吐槽優先留在內心；壓力越大，語言越收斂，真正恐懼時可以完全失去吐槽能力。
- 唐凜作為成年男性，可以自然注意成年女性的服裝、裸露程度、氣味、動作角度與身體線條，但觀察必須服務人物視角、尷尬、吸引、身分錯位或關係張力，不反覆使用固定順序的情色式身體掃描。
- 沈若冰：話少、準確、控制資訊量，不主動完整解釋自己。重要資訊可以由其他角色補充，使她保持難以判斷的多義性。
- 西苑：專業、完整、禮貌，偏工作式語氣，通常避免多餘情緒。
- 西奧：直接、單純，對正常人際界線與社會常識的理解有所缺失；不要讓她的說話方式變成單純賣萌。
- 不同角色應在句長、回答方式與資訊量上具有差異。連續對話以說話者名稱、動作、視線、停頓與空間位置維持辨識，不能為追求簡短而讓讀者混淆。

## 節奏原則

1. 不要使用「一件事情＝一章」的流水帳結構。
2. 一個重大事件應至少包含：前兆 → 發生 → 即時反應 → 心理消化 → 後果 → 新問題。
3. 重大事件後不要立刻用「隔天」、「幾天後」跳過人物反應，除非刻意追求斷裂效果。
4. 必須保留適量日常、探索、對話、環境細節與低事件密度場景，使讀者感受到角色真的在這個世界生活。
5. 不要求每一節都有高潮。允許安靜、壓抑、觀察型的小節。
6. 新設定不要連續大量傾倒。重要資訊應分散揭露，讓角色與讀者有時間理解。
7. 每次增加新事件時，先判斷是否應該補前兆、人物反應或後續影響，而不是直接加入下一個刺激事件。

## 章節結構

1. 正文採用「大章 → 小節」兩層結構。
2. 大章格式為「第一章、第二章、第三章……」。
3. 每章內採用編輯用小節編號，例如 `1-1`、`1-2`、`2-1`、`2-2`。
4. 每個大章代表一個完整的劇情或人物階段。
5. 每個小節負責一個具體事件、轉折、人物互動或心理變化。
6. 一般每章約 4～8 個小節，可依劇情自然增減，不為湊數硬拆。
7. 小節編號主要用於編輯與修改定位，正式閱讀版本可視需要隱藏。
8. 每個大章應盡量具有：開場狀態 → 壓力增加 → 核心事件 → 人物反應 → 狀態改變 → 下一章伏筆。
9. 網站以一個 Markdown 檔代表一個大章，章內使用 `## 1-1`、`## 1-2` 等標題。

## 修稿方式

1. 修改原稿時，優先保留原作的核心事件、主要人物、世界觀與作者原本想營造的氣氛。
2. 不得只是逐句潤色；必須同時檢查節奏、人物動機、因果、伏筆、資訊揭露、重複橋段與章節功能。
3. 如果原稿結構有問題，可以重新排序、合併、拆分或擴充場景，但不要未經必要就把故事改成完全不同的作品。
4. 發現設定矛盾、時間線錯誤、人物行為不合理或伏筆斷裂時，應主動指出。
5. 若有多種合理修改方向，先說明差異，再採用最符合既有故事核心的方案。
6. 原稿重要事件可以保留，但若成人描寫過度搶戲，優先改成心理、關係與懸疑導向，而不是直接刪掉整個事件。
7. 作者草稿決定「發生什麼」；修訂以語句、節奏、動作因果與情緒為主，不重新導戲或擅自改變事件順序。
8. `[刪除]` 代表確定不要，不得換句話補回；`[修飾]` 只修改指定位置；`[補]` 才新增必要內容。

## 敘事與文風

1. 維持第一人稱近距離敘事，原則上只描述唐凜當下能觀察、理解或推測到的資訊。
2. 保留唐凜偏口語、會吐槽、自我解嘲的個性。
3. 吐槽不能過度頻繁；恐怖、危險、悲傷或重大真相場景應允許氣氛維持，不要立刻用笑話破壞。
4. 避免過度使用「極其」、「瞬間」、「徹底」、「完全」、「瘋狂」等高強度詞彙。
5. 增加具體的感官、空間、動作與心理描寫，少用摘要式敘述直接交代數天經過。
6. 對話應讓不同角色具有可辨識的語氣，避免所有角色都使用同一種說話方式。
7. 整體目標是讓小說從「事件快速排列的網路小說草稿」提升為具有沉浸感、懸疑性、角色弧線與成人氣氛的長篇小說。
8. 日常與低壓場景可以較輕快；隨著危險、懸疑或心理壓力增加，應逐步降低吐槽與評論密度。
9. 避免讓每個段落都刻意製造金句、段子或反轉句。長篇需要保留自然、安靜與沒有刻意強調的段落。
10. 敘事風格以「易讀的日系輕小說節奏＋成人黑暗懸疑內容」為方向，但避免過度網路化、迷因化或時效性太強的用語。

## 用字與描寫

- 注意避免過度使用「開始」、「突然」、「感覺」、「覺得」、「似乎」、「好像」等摘要式或緩衝性詞語；若能透過具體動作、感官、注意力、環境或直接心理反應呈現，優先使用具體描寫。
- 特別避免反覆使用「我開始覺得……」、「我突然發現……」、「我感覺……」、「我好像意識到……」作為心理描寫的固定起手式。
- 同時注意「有點」、「其實」、「只是」、「甚至」、「不知道為什麼」、「不知不覺」等容易累積的口語緩衝詞，必要時刪除或改為更直接的敘述。
- 優先讓讀者從細節感受到異常、恐懼或人物心理，而不是直接由敘述者解釋「這裡很奇怪」、「我很害怕」、「我開始不舒服」。
- 增加具體的視覺、聲音、觸感、空間、距離與人物動作，但避免為描寫而堆砌形容詞。
- 心理描寫可以直接，但重要心理變化應盡量透過動作、選擇、注意力與聯想呈現。

## 場景與既定設定

- 重要場景與私人空間應自然描寫服裝、髮型、姿勢、空間配置、光線、氣味，以及反映角色性格、生活習慣、階級或秘密的物件；細節需參與人物塑造與氣氛，不寫成逐項盤點。
- 沈若冰的私人房間以樸素、整潔為基準，帶一點小女生式的粉紅與溫馨感。她在私人房內的既定服裝參考為短版細肩帶背心搭配高腰貼身短褲；動作與角度會使唐凜難以完全移開視線，但敘事仍以他的視角、尷尬、吸引與兩人的關係張力為主。
- 唐凜的長期偽裝不使用假髮。霜月透過生物技術加速頭髮自然生長，再以護理與造型管理維持「秦夢瑤」所需外觀。
- 筆狀審問裝置只需接觸約一秒並送出啟動脈衝；裝置離開後，由已觸發的神經反射自行持續，不是持續通電。
