## 章節結構

正文採「大章 -> 小節」兩層結構。

```text
第一章
├─ 1-1
├─ 1-2
├─ 1-3
└─ 1-N
```

## 結構原則

- 一般每章約 4 到 8 個小節，可依劇情自然增減。
- 大章代表一個完整劇情或人物階段。
- 小節負責一個具體事件、轉折、人物互動或心理變化。
- `1-1`、`1-2` 等小節編號主要作為編輯定位，前端閱讀模式可選擇隱藏。
- 每章盡量具有：開場狀態 -> 壓力增加 -> 核心事件 -> 人物反應 -> 狀態改變 -> 下一章伏筆。

## 建議檔案命名

尚未建立正文目錄前，先採用可讀、可排序、可擴充的命名方式。

```text
content/chapters/
├─ arc-01-frostmoon-manor/
│  ├─ ch01.md
│  ├─ ch02.md
│  └─ ch03.md
└─ arc-02-klein-academy/
   ├─ ch01.md
   └─ ch02.md
```

## 最小 Frontmatter

在網站載入 Markdown 或 MDX 前，先維持最小必要欄位。不要增加目前用不到的 metadata。

```yaml
---
title: "蛻皮"
chapter: 1
arc: "霜月莊園"
status: "draft"
---
```

## 建議狀態值

- `draft`: 草稿
- `revision`: 修訂中
- `ready`: 可進入閱讀版
