# 閱讀設計

## 方向

介面採日系輕小說與沉浸式電子閱讀器方向。小說正文是視覺主體，不使用管理後台、新聞列表或傳統部落格版型。

## 排版

- 正文使用適合中文長文的襯線字體。
- 桌面正文寬度約 720px，插圖可適度超出文字欄位。
- 手機保留 16px 以上安全邊距，正文行距略高於桌面。
- 支援深色／淺色模式與閱讀頁字級調整。
- 閱讀進度固定顯示於頁面頂端。

## 插圖

- 插圖應靠近對應段落，避免為裝飾而連續堆放。
- 優先使用 WebP 或 AVIF，PNG/JPEG 亦可。
- 每張圖必須有能描述畫面的替代文字。
- 正式插圖放在 `public/images/chapters/<arc>/<chapter>/`。
