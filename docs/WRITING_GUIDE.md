# WRITING_GUIDE

本文件記錄《我只是來打工的，沒人說過工作內容會變成這樣吧？》長期修訂原則，用於小說重構、續寫、審稿與內容一致性檢查。

## 作品方向

- 類型核心為黑暗懸疑、臥底、身分置換、身體改造、權力控制、人物關係與身分認同。
- 保留成人感、羞恥感、曖昧、壓迫感與身體改造元素，但不要改成純色情小說，也不要過度清水化。
- 成人相關內容必須服務至少一項功能：劇情推進、人物關係、心理變化、權力關係、身分錯位或懸疑資訊。
- 重複且沒有新劇情功能的成人橋段應縮短、淡化、合併或刪除。
- 性相關場景優先描寫心理、羞恥、控制、依賴、界線、恐懼與人物關係，降低器官、體液、尺寸與連續刺激細節。
- 強迫、控制、監禁、人體改造等情節可以存在，但敘事必須承認其侵犯性與心理後果，不要自動將其視為浪漫福利。

## 角色原則

- 唐凜的核心成長線為：被迫偽裝 -> 排斥 -> 適應 -> 熟練 -> 身分錯位 -> 唐凜與「秦夢瑤」產生心理衝突。
- 唐凜不應快速接受重大身體或身分改變。重要改變後必須安排心理消化與生活適應。
- 沈若冰必須保持多義性。讀者不能太早確定她究竟是在利用、培養、控制、保護唐凜，還是真正對他產生感情。
- 唐凜與沈若冰的信任、依賴、曖昧、背叛感與親密感必須循序發展，不得突然跳級。
- 西奧的核心放在「克萊因孩子」、異常能力、限制器、身世與心理依附，而不是單純作為成人橋段角色。
- 新角色必須具有明確的角色功能、欲望、秘密或衝突，不要只為單一場景服務後就消失。

## 節奏原則

- 不使用「一件事情 = 一章」的流水帳結構。
- 重要事件應包含：前兆 -> 發生 -> 即時反應 -> 心理消化 -> 後果 -> 新問題。
- 重大事件後不要立刻用「隔天」、「幾天後」跳過人物反應，除非刻意追求斷裂效果。
- 保留適量日常、探索、對話、環境細節與低事件密度場景，使讀者感受到角色真的在這個世界生活。
- 不要求每一節都有高潮。允許安靜、壓抑、觀察型的小節。
- 新設定不要連續大量傾倒。重要資訊應分散揭露，讓角色與讀者有時間理解。
- 每次增加新事件時，先判斷是否應補前兆、人物反應或後續影響，而不是直接加入下一個刺激事件。
- 第一章《蛻皮》固定橫跨約三個月；改造、恢復、日常生活與訓練交錯發生，不採「一天一項改造」的程序表節奏。詳細分週基準見 `docs/NOVEL_GUIDE.md`。

## 正式名稱與場景

- Arc 01 的正式名稱為「雙月苑」，日常可簡稱「雙月」；「霜月／霜月莊園」不再用於現行正文與介面。
- 雙月苑建築與空間的正式配置以 `docs/NOVEL_GUIDE.md` 為準，外觀圖像與重做清單以 `docs/IMAGE_GUIDE.md` 為準。

## 文風

- 維持第一人稱近距離敘事。
- 保留唐凜偏口語、會吐槽、自我解嘲的個性。
- 吐槽不能過度頻繁；恐怖、危險、悲傷或重大真相場景應允許氣氛維持，不要立刻用笑話破壞。
- 避免過度使用「極其」、「瞬間」、「徹底」、「完全」、「瘋狂」等高強度詞彙。
- 增加具體的感官、空間、動作與心理描寫，少用摘要式敘述直接交代數天經過。
- 對話應讓不同角色具有可辨識的語氣，避免所有角色都使用同一種說話方式。
